# Mine sider

En enkel oversigt over alle mine dashboards, spil og quizzer på GitHub Pages.

**Se siden:** https://ai-michelklos.github.io/minesider/

## Tilføj en ny side

Åbn `index.html` og find listen `GROUPS` i bunden. Kopiér en linje i den gruppe, siden hører til, og ret titel, sti, repo og beskrivelse.

Repoer med GitHub Pages, som ikke står på listen, dukker automatisk op under "Nye sider", så intet bliver væk.
