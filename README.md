# Mine sider

En enkel oversigt over mine dashboards, spil og guider på GitHub Pages og andre publicerede sider.

**Se siden:** https://ai-michelklos.github.io/minesider/

## Tilføj en ny side

Åbn `index.html` og find listen `GROUPS` i bunden. Kopiér en linje i den gruppe, siden hører til, og ret titel, URL, repo og beskrivelse. En side uden for GitHub Pages kan bruge en fuld webadresse som `url`; `label` og `code` kan angive en kort visningstekst og et direkte link til kildekoden.

Repoer med GitHub Pages, som ikke står på listen, dukker automatisk op under "Nye sider", så intet bliver væk.
